# Checklist de Estudos: React Avançado & Performance 🎓

Acompanhamento de estudos práticos de otimização de interfaces do usuário no ecossistema React.

---

## 📚 Tópicos de Estudo & Aplicação

- [x] **Renderização Otimizada**
  - [x] Uso de `React.memo` para evitar renderizações redundantes de cards de lista interativa.
  - [x] Uso de `useCallback` e `useMemo` para estabilizar referências de callbacks de drag and drop.
- [x] **Gerenciamento de Estado Global**
  - [x] Uso de Context API para dados leves de login de usuário.
  - [x] Uso de Zustand ou Redux para estados complexos de CRM e Kanbans.
- [ ] **Server Components & Frameworks Modernos**
  - [ ] Estudo de Server Actions e renderização no servidor (SSR) com Next.js v14+.
  - [ ] Carregamento progressivo de dados com Suspense e streaming de HTML.
