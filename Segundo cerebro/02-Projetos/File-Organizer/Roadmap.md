# 📅 Roadmap de Implementações — File Organizer

Fases de desenvolvimento do script de automação de arquivos.

---

- [x] **Fase 1: Script Básico**
  - [x] Estrutura de mapeamento por hashtable de extensões.
  - [x] Criação automática de diretórios de destino.
  - [x] Tratamento de colisão de nomes adicionando timestamp único.
- [ ] **Fase 2: Automação Contínua**
