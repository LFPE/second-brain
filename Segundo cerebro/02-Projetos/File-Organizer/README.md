# Projeto: File Organizer (Automação de Arquivos em PowerShell) 📂

Ferramenta automatizada em PowerShell que monitora pastas específicas (como a pasta de Downloads), identifica a extensão de novos arquivos e os move recursivamente para pastas organizadas por tipo, registrando logs detalhados de auditoria.
