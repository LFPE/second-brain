# 🧠 Lições Aprendidas — Portfólio

*   **Evitar Badges e Shields promocionais:** Utilizar tags personalizadas em HTML/CSS mantém o layout minimalista e evita requisições lentas de recursos de imagens externas.
*   **Hospedagem estática Edge é insuperável:** A velocidade de carregamento de arquivos puros de HTML/CSS em CDNs globais (como Cloudflare Pages) entrega melhor tempo de resposta se comparado a containers Docker tradicionais.
*   **Git History Limpo:** Inicializar repositórios com commits de entregas estruturadas (amends) evita histórico poluído com dezenas de mensagens insignificantes.
